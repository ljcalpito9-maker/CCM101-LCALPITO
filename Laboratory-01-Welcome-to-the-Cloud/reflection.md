Cloud Concepts Reflection
Cloud computing has become an important part of my daily life because many of the applications I use rely on cloud services. Three cloud services I regularly use are Google Drive, Facebook Messenger, and Canva. Google Drive allows me to store and access my files from any device with an internet connection. Facebook Messenger helps me communicate with my family, friends, and classmates instantly. Canva is a useful platform for creating presentations, posters, and other school projects.

These services are examples of the Software as a Service (SaaS) model because they provide complete applications that users can access through a web browser or mobile app without installing or managing the underlying infrastructure. In terms of deployment, Google Drive, Facebook Messenger, and Canva are primarily Public Cloud services because they are available to millions of users over the internet and are managed by their respective companies. This makes them convenient, accessible, and easy to use for everyday tasks.

Learning about Git and GitHub has helped me understand the importance of version control in cloud computing projects. Cloud infrastructure often involves multiple people working on the same files and configurations. Without version control, it would be easy to overwrite changes or lose important work. Git tracks every change made to a project, making it possible to review previous versions or restore files when needed. GitHub provides a platform where team members can collaborate, share code, review updates, and manage projects efficiently. Features such as branches and pull requests allow developers to work on different tasks without affecting the main project until the changes are ready. This reduces errors, improves teamwork, and keeps cloud-based projects organized.

Overall, this activity helped me realize that cloud computing is already a part of my everyday life. Understanding cloud service models, deployment models, and version control gives me a better appreciation of how modern technology supports communication, collaboration, and productivity.
