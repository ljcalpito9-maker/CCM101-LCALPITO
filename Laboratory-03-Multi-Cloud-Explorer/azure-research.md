# Microsoft Azure Research

## 1. Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It allows individuals, businesses, schools, and other organizations to use computing resources and services through the internet instead of relying completely on physical servers.

Azure provides different services that can be used for creating, running, and managing applications. These include virtual machines, databases, storage, networking, artificial intelligence, and other business solutions.

What I find interesting about Azure is that it works well with many Microsoft technologies. Organizations that already use products such as Windows Server and Microsoft 365 can connect them with Azure. As an Information Technology student, I see Azure as a useful platform for learning how companies use cloud technology to manage their IT infrastructure.

## 2. Global Infrastructure

Microsoft Azure has a large global infrastructure made up of regions and datacenters located in different parts of the world. These locations give organizations different options when deciding where to deploy their applications and store their data.

I think having many locations is important because companies may have users from different countries. By choosing a suitable Azure region, organizations can consider factors such as application performance, availability, and data requirements.

For example, a company with many customers in Asia could choose an Azure region that is closer to its users. This can help provide a better experience compared with hosting the application in a location that is very far away.

## 3. Cloud Management Console

The main web-based management interface for Azure is called the **Azure Portal**. It allows users to create, configure, manage, and monitor different Azure resources.

Through the Azure Portal, users can manage services such as virtual machines, databases, storage, web applications, and networks. The portal also allows users to create dashboards where important resources and information can be viewed in one place.

As a student, I think the Azure Portal is helpful because it provides a visual way to learn about cloud computing. It allows me to see the different services available and understand how cloud resources are managed.

## 4. Four Core Azure Services

### 1. Azure Virtual Machines

**Azure Virtual Machines** provide virtual computers that can run operating systems such as Windows and Linux. I think of a virtual machine as a computer that can be created and used through the cloud without having to physically purchase the server.

For example, a company could use an Azure Virtual Machine to run a website, business application, or internal system.

### 2. Azure Blob Storage

**Azure Blob Storage** is a cloud storage service designed for storing large amounts of unstructured data. It can store files such as images, videos, documents, backups, and other types of data.

I think Blob Storage is useful for applications that need to handle many files. Instead of storing everything on the application's physical server, the files can be stored in the cloud.

### 3. Azure SQL Database

**Azure SQL Database** is a managed relational database service from Microsoft. It can be used to store organized information such as customer accounts, products, orders, and transactions.

One advantage of using a managed database service is that organizations do not have to handle all aspects of the physical database infrastructure themselves. This allows developers to focus more on creating and improving their applications.

### 4. Azure Virtual Network

**Azure Virtual Network** provides a private networking environment for Azure resources. It allows virtual machines and other cloud resources to communicate with each other while giving organizations control over their network configuration.

I think this service is important because cloud resources still need networking and security. Just like computers in an organization need a properly configured network, cloud resources also need a controlled environment for communication.

## 5. Three Advantages of Azure

### 1. Microsoft Integration

One major advantage of Azure is its strong connection with other Microsoft technologies. Organizations that already use Windows Server, Microsoft 365, and other Microsoft products can integrate these technologies with Azure.

For this reason, I think Azure can be a good option for schools and businesses that already depend on Microsoft products.

### 2. Global Infrastructure

Azure has infrastructure in many locations around the world. This gives organizations more choices when deciding where to deploy their applications and store their data.

For companies that operate internationally, having different deployment locations can be useful because they can choose locations that are suitable for their users and business requirements.

### 3. Scalability and Flexibility

Azure allows organizations to adjust their cloud resources depending on their needs. They can choose different amounts of computing power, storage, networking, and other resources.

For example, if a company's application starts receiving more users, it can increase its resources to handle the additional workload. This can reduce the need to purchase new physical hardware whenever the company's requirements increase.

## 6. Typical Enterprise Use Cases

Microsoft Azure can be used by many different organizations for different purposes. Some common uses include:

* **Web application hosting** – Companies can use Azure to deploy and run websites and web applications.
* **Virtual machines** – Organizations can move Windows or Linux servers to Azure Virtual Machines.
* **Database management** – Businesses can use Azure SQL Database for applications that need structured data.
* **File and data storage** – Azure Blob Storage can store documents, images, videos, backups, and other files.
* **Hybrid cloud environments** – Organizations can connect their existing on-premises infrastructure with Azure services.
* **Microsoft-based systems** – Businesses that already use Microsoft technologies can use Azure to expand their existing IT infrastructure.
* **Artificial intelligence and analytics** – Organizations can use Azure services to develop AI applications and analyze data.

For example, a university that already uses Windows Server and Microsoft 365 could use **Azure Virtual Machines** for some of its servers, **Azure SQL Database** for applications that need databases, **Azure Virtual Network** for networking, and **Microsoft Entra ID** for identity and access management.

This example shows how Azure can be useful for organizations that already use Microsoft technologies.

## My Understanding of Microsoft Azure

After researching Microsoft Azure, I learned that it is not only used for hosting websites. It provides many different cloud services that can support computing, storage, databases, networking, security, artificial intelligence, and business applications.

For me, one of the most interesting parts of Azure is its integration with Microsoft's existing technologies. As an IT student, learning Azure can help me understand how organizations can move from traditional physical servers to cloud-based infrastructure.

I also learned that cloud computing can give organizations more flexibility because they can choose the resources they need and adjust them when their requirements change. Overall, this research helped me understand how Azure can be used to build and manage modern IT systems without depending completely on physical hardware.
