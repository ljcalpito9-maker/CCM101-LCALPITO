# Mission Reflection

After completing Mission 3, I gained a better understanding of **AWS, Microsoft Azure, and Google Cloud Platform (GCP)**. Before doing the activities, I knew that cloud computing was used to access resources through the internet, but I did not fully understand how the different cloud platforms worked. Through this mission, I was able to compare their services and understand how they can be used by different organizations.

Among the three platforms, **Google Cloud** caught my attention the most. I became interested in its services related to **artificial intelligence, machine learning, data, and Kubernetes**. As an Information Technology student, I think these technologies are important to learn because they are becoming more common in modern software development and cloud computing.

I also learned that AWS, Azure, and Google Cloud have many similar services. All three platforms provide virtual machines, storage, databases, networking, security, and other tools for building applications. However, they use different names for their services and have different strengths. This helped me realize that comparing cloud platforms is not only about looking at the services they offer but also understanding which platform fits a particular situation.

Another important lesson I learned is that **business requirements should be considered when selecting a cloud provider**. For example, I would consider Azure for an organization that already uses Windows Server, Microsoft 365, and other Microsoft technologies. For an organization focused on artificial intelligence and machine learning, I would consider Google Cloud. AWS can be a good option for businesses that need a wide selection of services and the ability to scale their applications.

Being a Cloud Solutions Consultant in this activity also taught me that choosing a cloud platform should not be based only on popularity or personal preference. Before making a recommendation, I should first understand the client's **budget, existing systems, application requirements, number of users, security needs, and future plans**. This makes the decision more practical and suitable for the organization.

Another part of the mission that I found useful was building my **GitHub Cloud Computing Portfolio**. I was able to organize my research about AWS, Azure, and Google Cloud, along with my comparison tables, client recommendations, decision matrix, Linux investigation, screenshots, and reflection. I also became more comfortable using **Markdown and GitHub** to organize and present my work.

Overall, Mission 3 gave me a better understanding of how cloud computing is used in real-world situations. I learned that AWS, Azure, and Google Cloud all have useful features, but the best choice depends on the needs of the organization. This mission also helped me improve my technical knowledge and gave me a better idea of how cloud technologies can be applied in the IT industry.
