# Google Cloud Platform (GCP) Research

## 1. Brief Overview

**Google Cloud Platform (GCP)**, now commonly known as **Google Cloud**, is a cloud computing platform developed by Google. It provides different services that allow individuals, developers, businesses, and organizations to create, run, store, and manage applications through the internet.

Google Cloud offers many services that are also available from AWS and Microsoft Azure, such as virtual machines, storage, databases, networking, and security. However, one thing that makes Google Cloud interesting is its strong focus on **artificial intelligence, machine learning, data analytics, and Kubernetes**.

As an Information Technology student, I find Google Cloud useful to study because modern applications are increasingly using data, AI, and cloud-based technologies. Learning Google Cloud can help me understand how organizations can run applications and process large amounts of information without depending completely on physical servers.

## 2. Global Infrastructure

Google Cloud has a global infrastructure made up of **regions and zones**. Regions represent geographic locations, while zones are separate areas within those regions where cloud resources can be deployed.

Having multiple regions and zones is useful for organizations that have users in different parts of the world. Companies can select locations that are appropriate for their applications based on factors such as performance, availability, and data requirements.

For example, a company with customers in different countries can deploy its application in suitable locations to provide a better experience for its users. Using multiple zones can also help reduce the impact of problems that may affect one location.

## 3. Cloud Management Console

The **Google Cloud Console** is a web-based interface that allows users to manage their Google Cloud resources. Through the console, users can create and manage virtual machines, storage, databases, networks, Kubernetes clusters, and other services.

The console also provides information about projects, resources, billing, and other settings.

As a student, I think the Google Cloud Console is helpful because it gives me a visual way to understand cloud computing. It allows me to explore different services without immediately having to use complicated commands.

Google Cloud also provides **Cloud Shell and command-line tools**, which can be useful when users become more familiar with the platform.

# 4. Four Core Google Cloud Services

## 1. Compute Engine

**Compute Engine** provides virtual machines that can be used to run applications and workloads in Google Cloud.

I think of Compute Engine as a computer that is hosted in the cloud. Instead of purchasing a physical server, an organization can create a virtual machine and select the resources it needs.

For example, a company could use Compute Engine to host a website, run an application, or perform computing tasks.

## 2. Cloud Storage

**Cloud Storage** is an object storage service used to store different types of data, including documents, images, videos, backups, and other files.

I think of it as online storage designed for applications and organizations that need to handle large amounts of data.

For example, a mobile application could use Cloud Storage to save profile pictures, documents, videos, or other files uploaded by users.

## 3. Cloud SQL

**Cloud SQL** is a managed relational database service provided by Google Cloud. It can be used to store structured information such as customer accounts, products, orders, transactions, and other records.

One advantage of Cloud SQL is that organizations can use a managed database instead of having to maintain the entire database infrastructure themselves.

This allows developers to spend more time working on their applications rather than handling every part of the database server.

## 4. Google Kubernetes Engine (GKE)

**Google Kubernetes Engine (GKE)** is a managed Kubernetes service provided by Google Cloud. It is used for deploying and managing containerized applications.

I find GKE interesting because Kubernetes is commonly used in modern software development. It helps organizations manage applications that are built using containers.

Google's connection to Kubernetes also makes GKE an important service to learn for students who are interested in cloud-native application development.

# 5. Three Advantages of Google Cloud

## 1. AI and Machine Learning

One of the major strengths of Google Cloud is its support for **artificial intelligence and machine learning**.

Organizations can use Google Cloud services and computing resources to develop and run AI applications without having to purchase expensive hardware themselves.

I think this can be especially useful for companies that are working on AI-based products and research.

## 2. Kubernetes and Container Support

Another advantage of Google Cloud is its strong support for **Kubernetes and containerized applications**.

With GKE, organizations can deploy and manage container-based applications using a managed Kubernetes environment.

As an IT student, I think learning Kubernetes together with Google Cloud is useful because containers and cloud-native technologies are becoming common in modern software development.

## 3. Global Infrastructure and Scalability

Google Cloud provides infrastructure in different regions and zones around the world. This allows organizations to build applications that can serve users in different locations.

Cloud resources can also be increased as an application grows. For example, a small application can start with limited resources and use additional resources when the number of users increases.

# 6. Typical Enterprise Uses

Google Cloud can be used by many different organizations. Some common uses include:

* **Artificial Intelligence and Machine Learning** – Organizations can develop and run AI and machine learning applications.
* **Data Analytics** – Companies can process and analyze large amounts of information.
* **Web Application Hosting** – Businesses can host websites and application backends.
* **Containerized Applications** – Organizations can use GKE to deploy applications using containers and Kubernetes.
* **Database Systems** – Businesses can use Cloud SQL and other database services to manage application data.
* **File and Object Storage** – Organizations can use Cloud Storage for files, backups, images, videos, and other data.
* **Global Applications** – Companies can deploy resources across different regions and zones to support users in different locations.

For example, an AI research company could use **Compute Engine** for computing tasks, **Cloud Storage** for datasets, **Cloud SQL** for application information, and **GKE** for running containerized AI applications.

This shows how several Google Cloud services can work together to create a complete cloud-based system.

# My Understanding of Google Cloud

After researching Google Cloud, I learned that it is more than just a platform for hosting websites and virtual machines. It provides services for computing, storage, databases, networking, data analytics, artificial intelligence, and containerized applications.

Personally, I find Google Cloud interesting because of its strong focus on **AI, data, and Kubernetes**. These are technologies that are becoming increasingly important in the IT industry.

As an IT student, learning Google Cloud can help me understand how modern applications are developed and managed in the cloud. It can also give me experience with technologies that are commonly used in modern software development.

Compared with AWS and Azure, I would consider Google Cloud a strong option for organizations that focus on **artificial intelligence, machine learning, data analytics, and cloud-native applications**.

However, I also learned that Google Cloud is not automatically the best choice for every organization. The best platform depends on factors such as the company's budget, existing technology, security requirements, workload, and future plans.
