# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services, commonly known as AWS, is a cloud computing platform provided by Amazon. It allows businesses, organizations, and developers to use computing resources over the internet instead of purchasing and maintaining their own physical servers.

AWS offers different services for many IT needs, such as hosting websites, storing files, running applications, managing databases, and creating networks. One thing I find useful about AWS is that users can choose the resources they need and increase them when their projects grow. This can help organizations avoid spending too much money on physical hardware.

## Global Infrastructure

AWS operates through a global infrastructure that includes **Regions and Availability Zones**. A Region is a geographic area where AWS has cloud infrastructure, while Availability Zones are separate locations within a Region.

I think this setup is important because it can help companies make their applications more reliable. If a problem happens in one Availability Zone, resources can be placed in another Availability Zone to help keep the application available.

## AWS Management Console

The **AWS Management Console** is a website that allows users to manage their AWS services and resources. Through the console, users can create virtual machines, manage storage, configure networks, monitor resources, and access different AWS services.

For me, the AWS Management Console is useful for beginners because it provides a graphical interface. Instead of typing commands immediately, students can see the available services and learn what each service does.

## Four Core AWS Services

### 1. Amazon EC2

**Amazon Elastic Compute Cloud (EC2)** provides virtual servers that can be used to run applications and websites in the cloud. I think of EC2 as a computer that we can rent and use through the internet instead of buying a physical server.

EC2 can be useful for companies because they can choose the amount of computing resources they need. AWS also provides scaling features that can help increase or decrease resources depending on the workload.

### 2. Amazon S3

**Amazon Simple Storage Service (S3)** is a storage service used for saving different types of files and data. It can store images, videos, documents, backups, and other files.

I think S3 is useful because organizations can store large amounts of data in the cloud without depending only on the storage available on their own computers or physical servers.

### 3. Amazon RDS

**Amazon Relational Database Service (RDS)** is a managed database service. It helps organizations set up and manage relational databases without having to handle all of the database infrastructure manually.

For example, a company could use RDS to store customer information, product details, transactions, or other important data needed by an application.

### 4. Amazon VPC

**Amazon Virtual Private Cloud (VPC)** allows users to create a private and controlled network within AWS. It provides features for managing IP addresses, subnets, route tables, and network security.

For me, VPC is important because cloud-based applications still need proper networking and security. It helps organizations control how their cloud resources communicate with each other and with the internet.

## Three Advantages of AWS

### 1. Many Available Services

One of the advantages of AWS is the large number of services it provides. There are services for computing, storage, databases, networking, security, analytics, artificial intelligence, and many other IT needs.

### 2. Scalability

AWS allows organizations to adjust their resources depending on their needs. For example, if a website suddenly gets many users, the company can increase its computing resources to help handle the additional traffic.

### 3. Global Infrastructure

AWS has cloud infrastructure in different parts of the world. This gives organizations more choices when deciding where to deploy their applications. It can also help improve application availability and performance for users in different locations.

## Common Enterprise Uses of AWS

AWS can be used by different types of businesses and organizations. Some common uses include:

* Hosting websites and web applications
* Developing mobile applications
* Storing company files and backups
* Running databases
* Supporting online shopping systems
* Performing data analysis
* Running artificial intelligence and machine learning applications
* Creating disaster recovery systems
* Hosting business applications

For example, an online shopping company could use **EC2** to run its website, **S3** to store product images, **RDS** to store customer and transaction information, and **VPC** to manage and secure its network.
